# Ponte UI ↔ host (WebView2)

Contrato entre as telas HTML (`src/MeuClima/Web/`) e o host C#. Mensagens JSON via
`window.chrome.webview.postMessage(obj)` (UI → host) e `window.chrome.webview.addEventListener('message', e => e.data)`
(host → UI). Duas páginas: `flyout.html` (bandeja, 380 px) e `central.html` (janela ~1000×700).
Ambas servidas em `https://app.meuclima/` (mapeamento de pasta virtual). Sem rede externa além de Google Fonts
(opcional, com fallback local).

## UI → host

| type | campos | efeito |
|---|---|---|
| `ready` | — | host responde com `state` |
| `command` | `deviceId`, `command` | envia ao aparelho; conta como ajuste manual (pausa automações 60 min) |
| `pause` | `deviceId`, `minutes` | pausa automações do aparelho |
| `resume` | `deviceId` | retoma automações |
| `nightMode` | `deviceId`, `on` | ativa/cancela Modo noite |
| `openCentral` | `tab?` | abre a central (da bandeja) |
| `closeFlyout` | — | esconde a bandeja |
| `resize` | `height` | só a bandeja: altura do conteúdo em px; o host ajusta a janela (160–640) |
| `getInsights` | `deviceId?`, `days` (1 ou 7) | host responde `insights` |
| `saveRule` | `rule` (config completo com `tipo`) | cria ou atualiza (por `id`) |
| `deleteRule` | `id` | remove |
| `toggleRule` | `id`, `enabled` | liga/desliga regra |
| `saveSettings` | `settings` (parcial) | grava ajustes |
| `searchCity` | `query` | host responde `cities` |
| `setCity` | `city` (objeto de `cities`) | grava cidade |
| `setCredentials` | `apiKey`, `refreshToken` | valida (lista aparelhos) e grava protegido; responde `toast` |
| `checkUpdate` / `installUpdate` | — | autoatualização; `checkUpdate` termina com um `toast` (`ok` ou `error`) |
| `quit` | — | encerra o app |

`command` aceita: `{kind:"power",on}`, `{kind:"mode",value}`, `{kind:"fan",value}`, `{kind:"target",value}`,
`{kind:"timer",seconds}` (0 cancela), `{kind:"oscillate",on}`, `{kind:"eco",on}`.
